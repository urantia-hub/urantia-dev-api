## Clean-room rules

This translation must be an independent work, made only from the public-domain English. Existing translations of this book are copyrighted. These rules keep them out of the work.

1. Use only this packet. Do not open other files, except to write your output file.
2. Do not search the web and do not fetch web pages.
3. You can use the urantia.dev MCP server to check the meaning of a term or the context of a paragraph. Use it in English only: never set a `lang` value.
4. Do not consult, quote, or reproduce any existing translation of this book, even from memory. If a sentence comes to you in the words of a published translation, write it again in your own words.
5. When two forms are equally good, choose the plain, natural form. Do not choose a form because a published translation uses it, and do not avoid a form for that reason.
